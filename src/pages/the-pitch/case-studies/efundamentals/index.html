e.fundamentals

Type: Website

Built using: WordPress (Oxygen page builder)

A responsive WordPress website and design system for an international marketing and analytics platform provider.

Project Overview

e.fundamentals required a website to showcase their services and methodology, handling a large amount of content that needed to be easy to update, consistent in aesthetic, and offer a wide variety of re-usable content blocks to convey complex content appealingly.

The result was a design system containing over 20 unique components, plus font, colour, sizing and branding elements.

Performance & Technology

The client had previously used Divi (a WordPress page builder known for slow, bloated output). After investigating alternatives, Oxygen was recommended — it delivered better performance and produced creditable scores despite some third-party tools and limited server control.

Performance Scores: GTmetrix Grade B, 86/83

Features

The site features:

  • Large resource section for blog posts, media and resources
  • Internationalisation for different content across international markets
  • Extensive custom forms and data capture elements to increase user engagement

Testimonial

On top of that the speed of activity was strong, responsive and no request we had was ever pushed back on. Absolutely delighted with the finished product."
