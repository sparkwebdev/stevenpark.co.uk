Bandstands

Type: iOS and Android App

Built using: React, Expo

Credits: Design by Rosy Naylor

A cross-platform app allowing participants to navigate and discover 8 historical bandstands across Edinburgh and Musselburgh. In collaboration with the Arty Walk Porty project, with soundscapes by composer Ross Whyte.

Project Overview

The Arty Walk Porty project conceived an immersive sound-based performance and exhibition to celebrate and commemorate 8 historical bandstands across Edinburgh & Musselburgh. Events included musical performances across various locations, culminating in a procession along Portobello promenade.

"Marking the spaces of where bandstands once stood, and some still do, this project brings together a sense of discovery through sound..."

— Rosy Naylor, Platform Designs, Edinburgh

The mobile app encourages users to visit all 8 bandstand sites. Each location features an accompanying melodic loop composed by sound artist Ross Whyte and performed by the Portobello Community Choir.

How It Works

The user is guided towards each location; when close, the sound file begins playing, increasing in volume as they approach. Once near enough the location is 'unlocked' — or the user can scan a QR code from physical markers at each site.

As each location is collected, the user is rewarded with imagery and historical information; the loop becomes playable. When 3+ are visited, collected loops can be combined into a unique composition. Together all loops form a complete song: 'The Great Exhibition'.

Technology

Built with React and the Expo framework (React Native). Device APIs used include:

  • Camera (QR code scanning)
  • Geolocation and Device Motion (maps and waypoints)
  • Keep Awake (keeping app and sound active)

Visual Design

Minimal yet playful; green and purple colour scheme; old photographs of historic bandstands.
