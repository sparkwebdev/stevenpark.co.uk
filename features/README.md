# Features Working Directory

Source materials and working files for site features.

Each feature has its own subdirectory containing:
- Raw source data (CSVs, exports, notes)
- Curation notes and decision logs
- Extraction scripts (if needed)
- TODO lists specific to that feature

**Related:** See `docs/features.md` for the official feature index and status tracking.

---

## Structure

```
features/
├── README.md (this file)
├── web-dev-articles/
│   ├── README.md (feature notes)
│   └── articles.md (source from CareerHub)
├── music-collection/
│   └── (source materials)

│   └── (source materials)
└── til/
    └── (Today I Learned source)
```
